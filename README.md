## 🚀 Get Started

### Before you install

- **Device:** Android phone or tablet running **Android 7.0 (API 24)** or later.
- **Account:** An active, authorized IMISS staff account.
- **First sign-in:** Change any temporary password through the main IMISS web portal before using the app.

### Install from GitHub Releases

1. Open **[Latest Release](https://github.com/nekofied143/IMISSReceiver/releases/latest)**.
2. Under **Assets**, download the Android `.apk` file.
3. Open the downloaded APK and follow Android's installation prompts.
4. If prompted, allow installation **from that source** only after confirming the APK came from this repository.
5. Launch **IMISS Logs** and sign in with your IMISS staff credentials.

> [!IMPORTANT]
> Only install APKs from the [official Releases page](https://github.com/nekofied143/IMISSReceiver/releases). Avoid third-party mirrors. Revoke the **Install unknown apps** permission afterward if it is no longer needed.

### Keep the app up to date

**Already installed? Update directly inside IMISS Logs.** There is no need to uninstall the existing app or manually download an APK for routine updates.

1. Use the app's built-in update feature when an update is available.
2. Follow the in-app and Android prompts.
3. Reopen the app if requested.

For version details and changes, see the [release notes](https://github.com/nekofied143/IMISSReceiver/releases). If an update fails, contact your IMISS administrator rather than uninstalling as a first step.

## 🧭 Using IMISS Logs

### 1. Find your assigned work

Sign in and choose a status tab:

| Status | Meaning |
| --- | --- |
| **Open** | Assigned work that has not yet started. |
| **In Progress** | Work currently being handled. |
| **Resolved** | Work marked as completed. |

Tap a tab or swipe horizontally to switch views. **Pull down** to refresh.

### 2. Move a ticket forward

```text
Open  ── Start Progress ──▶  In Progress  ── Mark Resolved ──▶  Resolved
```

Select an assigned ticket, tap **Start Progress** when work begins, and tap **Mark Resolved** when finished. Add remarks during either action when documentation is needed.

### 3. Refer active work

For a colleague or next-shift handoff, select an active ticket and tap **Refer**. Choose the receiving staff member, select a category, enter the **required reason**, and confirm.

| Referral category | When to use it |
| --- | --- |
| **Next Duty** | Passing work to the next duty shift. |
| **Unable to Perform** | You cannot carry out the task. |
| **Other** | Another handoff reason. |

A specific reason helps the receiving staff member continue the work.

## 🔔 Notifications

To receive assignment alerts, allow notifications for IMISS Logs in your Android settings. The exact menu depends on your device, but it is generally under **Settings → Apps → IMISS Logs → Notifications**.

If alerts are delayed or missing, check connectivity, **Do Not Disturb**, and whether device battery settings restrict background activity. Avoid turning off system-wide battery protections unnecessarily. You can always open the app and **pull down to refresh**.

## 🛠️ Troubleshooting

| Problem | Suggested action |
| --- | --- |
| **Can't sign in** | Check credentials and change any temporary password on the main IMISS portal. |
| **Ticket missing** | Check all three status tabs, refresh, and confirm the work was assigned to your account. |
| **No new-assignment alerts** | Check notification permissions, connectivity, Do Not Disturb, and background restrictions. |
| **Update doesn't complete** | Check connectivity, retry the built-in update, then contact your IMISS administrator. |
| **App can't reconnect** | Check access to the IMISS service and contact your administrator if the problem continues. |

## 🔒 Privacy & Responsible Use

Work-log concerns and remarks may contain operational or sensitive information. Follow your organization's policies:

- Include only details necessary to document and resolve the ticket.
- Never enter passwords, access tokens, or unnecessary patient or personal information in remarks or referrals.
- Do not share ticket details, screenshots, or credentials with unauthorized people.
- Report suspected misuse or accidental disclosure through approved internal channels.

> [!NOTE]
> These are staff usage guidelines, not claims about the app's encryption, data storage, or retention implementation.

## 💬 Support & Access

IMISS Logs is intended for **authorized IMISS technical staff** and works alongside the existing IMISS Work Logs system.

For sign-in issues, missing assignments, update problems, or access requests, contact your designated **IMISS system administrator**. When reporting a problem, provide the app version (if known), Android version, a short description, and steps to reproduce it. **Do not post credentials, patient information, or sensitive ticket details in public GitHub issues.**
